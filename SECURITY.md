# Security

Report a vulnerability privately, never in a public issue: use GitHub's "Report a vulnerability"
button in this repository's Security tab, or write to unheard@gwendall.com.

What matters most here:

- anything that would let a recording, a location or a time leave a phone without its owner
  pressing "Give this recording", or leave it without the anonymisation of `lib/anonymize.ts`;
- anything that would let someone read or delete other people's donations in the private store;
- a way to run code in this repository's CI with more than a pull request's read-only token.

You will get an answer within a week.
